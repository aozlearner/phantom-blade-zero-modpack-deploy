# 当前组合的工程约束

## 分层与锁定

PBZModLoader 1.0.4 使用 `platform/steam/version.dll` 和 `ProjectPBZ/PBZModLoader`，运行衣柜、语音与材质保护脚本。UE4SS 4.0.0 使用 `platform/steam/dwmapi.dll`，运行 Map Collectible Markers 2.2.7。两条加载链都在清单里，不能只复制衣柜文件。

`ProjectPBZ/Content/JavaScript/PBZModLoader` 下只部署 bootstrap 和 manager。generated-config、generated-mods 和 generated-reloads 由加载器生成，不能复制旧缓存当作源代码。现有只读资源扫描插件也保留在基线中，它可能在游戏 Saved 目录生成诊断文件，这些输出不进入资源包。

8 个有效 Paks 子目录提供 24 个容器文件。原白赤练、虚空等原始容器保留原始身份，不能随意经 legacy 转换重打包；曾出现材质丢失和骨架引用错误。WardrobeExpansion 容器及其脚本是同一版本整体，不能独立替换其中一个。运行时引擎识别为 UE5.7，现有资源序列化使用已验证的 UE5_6 profile，这两个版本概念不可混用。

## 衣柜与动作

68 个稳定衣柜 ID 见 outfits.json。角色通过独立注册提供者加入衣柜，不把原主角默认网格替换成另一个角色。当前主表保留原有条目并追加独立条目，必须作为已经合并的整体部署；不能把每个上游包的主表按文件复制顺序互相覆盖。

玩家继续使用主角动作与操作。角色身体的适配动画、头部/面部跟随、衣料、头发、眉睫和额外挂件各有明确绑定。不可直接把 NPC 控制器或完整 Boss 动画蓝图装到主角上。头身分离通常需要检查骨架空间与跟随链，不能用整体缩放掩盖。

舞狮二阶段狮头使用独立挂件和已修正的头部挂点；铁鬼、力者、彭猛、小雪、锯者保留各自缩放和部件过滤。某些源资产包含不需要的第二角色或武器部件，不能重新开启整个组合网格。具体模型逻辑保存在锁定资源包，不在安装阶段重新生成或猜测。

## 声音

独立 `pbz-female-attack-voice` 插件拥有女性战斗语音路由；外观脚本不重复挂一套语音替换。按当前衣柜 ID 和声音类别匹配，能使用角色自己的对应声音时使用本人；该类别缺失则退到沐小葵。攻击、受伤、跳跃/闪避发力都应检查。原版衣装保持主角男声，剧情对白不在替换范围内。头发保护名单包含男性条目，不能直接当作女性语音名单。

## 头发与材质

切武器、闪现或换装可能重新分配材质或更换组件。材质保护跟踪当前角色及其组件，验证资产引用有效后恢复该角色预期材质；不使用全局材质替换。切换角色、对象失效和卸载时清理缓存与引用，避免把上一个角色的颜色带到新衣装。玉儿受控与炼邪尤其需要连续闪现后验证。静态截图不能证明这个问题已消失。

## 缩略图

优先使用游戏内角色图鉴图；没有适用图的条目通过 portraits PNG 与 PortraitIcons 适配衣柜按钮。图片、衣柜 ID、图标绑定脚本和表引用必须一起安装。不要通过修改另一衣装的公共图标解决单个角色缺图。部署清单锁定图片和脚本的哈希。

## 安装事务

安装流程：检查版本/进程 → 检查冲突 → 全量验证并暂存包 → 备份旧受管理文件和存档 → 持久化事务 → 分批检查进程并写入 → 全量哈希验证 → 标记完成。

计划只接受不存在的目标、已经一致的目标、或本工具上次安装且未被修改的目标。升级可移除本工具先前管理、现版本不再需要的文件。未知 MOD 不自动清理。路径拒绝逃逸、重复大小写、Windows 设备名、符号链接、junction、硬链接和 ZIP 链接条目。

备份位于用户指定的私人目录；失败保留 receipt，人工触发回滚。工具在每批写入前检查进程，但无法阻止用户在检查间隙主动启动游戏，因此安装期间必须保持游戏关闭。回滚前验证所有受影响备份和当前哈希，用户后来改过的文件不强行覆盖。存档仅备份，不自动回写。
