## 可复现安装需要什么

1. 此仓库的固定版本。
2. 相同 Steam build 的合法游戏安装。
3. 与 current.lock.json 完全匹配的资源 ZIP，由维护者从参考安装 `export` 得到，或由获得各资源的使用者按清单组装。

本地已有完整基线 ZIP；它与公开代码仓库分开放置。没有这个输入时，公开工程仍可检查版本、审查清单、运行测试，但不能凭哈希还原缺少的模型或定制脚本。
