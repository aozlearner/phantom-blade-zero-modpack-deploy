# 验证与已知边界

## 工具验证

`tests/test_deploy.py` 使用临时虚拟游戏目录，覆盖首次安装、相同内容重复安装、升级和移除旧文件、逆序回滚、存档备份但不回写、用户文件漂移、未知 MOD 冲突、损坏 ZIP、路径攻击、写入中断恢复、损坏备份、游戏进程保护、版本限制与并行事务锁。

真机 `verify` 只读取 847 个部署文件。资源导出后再次从 ZIP 解压读取并核对每个 SHA-256，确保资源包与清单相符。测试通过不代表已经在其他电脑或新游戏版本中验证。

## 玩家验证

安装工具不会自动启动游戏。玩家下次正常游玩时检查：

- 衣柜能看到需要的条目与缩略图，原版衣装和原来正常的角色仍能使用。
- 幻鬼显示浅色外搭，绿裙独立条目不再出现；白赤练两种状态分别可选。
- 选几个骨架差异大的角色，待机、跑动、攻击、闪避、跳跃、切武器，检查头身连接、手臂、衣料和武器挂件。
- 虚空、炼邪、玉儿受控等连续切武器和闪现，头发保持预期颜色；换装再换回来继续观察。
- 女性角色攻击、受伤、跳跃/闪避为本人或沐小葵声音；切回原版为男声；剧情对白正常。
- 地区地图出现未收集物品标记，已收集的会隐藏。地图 `F` 打开筛选，`V` 追踪指向物品，`N` 切换最近物品追踪；手柄键位见资源包中插件 README。基线未启用点击传送。

标题画面资源扫描只能证明资源可加载、部件/骨架/材质引用成立，不能证明加载存档后的战斗没有问题。玩家确认与自动检查结果应分开记录。

## 维护新基线

新游戏版本或任何角色更新需重新核对原生资产、表条目、注册 ID、语音范围、材质清理、缩略图和实机动作。更新清单必须源于已验证的文件，不能只是修改 SHA-256 来让一个未知包通过。保存上一版本清单与独立资源包，以便定位变化。配置文件被玩家更改时也会报告差异，这是精确基线校验的预期行为。
