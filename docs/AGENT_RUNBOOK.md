# Agent 执行手册

本项目独立运行。不要查找、安装或调用本机 Skill，也不要使用历史聊天中的磁盘路径。

1. 读 `README.md`、`profiles/current.lock.json` 和 `profiles/outfits.json`。询问或从用户本机 Steam 库确定游戏根目录。基线只支持 build 26367565；新版本不能靠修改版本号绕过检查。
2. 确认用户已提供本基线资源 ZIP。没有资源包时，说明缺少哪个输入，不要把公开仓库误称为完整 MOD 下载，也不要用上游原版覆盖当前定制脚本。上游下载入口见 SOURCES。
3. 使用 `check-bundle` 完整验证 847 个条目，再执行 `plan`。所有路径由命令参数指定，不把个人绝对路径写回公开清单。
4. 将冲突清单变成具体处理方案。原衣装保留；已有正常的弦者、玉妖等不应被其他表或替换包覆盖。未知 MOD 先备份、确认用途，禁止为了让计划通过而批量删除。
5. 用户仍在游戏时，只做只读准备。得到已保存退出的信息后再安装；仍须由工具检查进程。受限环境看不到真实进程时先取得相应执行权限，不删掉保护代码。
6. 安装会备份游戏目录、本机 LocalAppData 下的 `.sav`，以及 Steam `userdata/*/4115450` 中的文件；Steam 目录识别失败需给 `--steam-userdata`。备份含私人信息，必须置于公开仓库之外。
7. 执行 `install` 并记录 transaction；失败先恢复事务，不重复盲目安装。执行 `verify`，报告匹配总数和差异。
8. 安装结束不启动游戏。若需要引擎资源扫描，另行取得本次启动许可，只到标题画面、不加载存档；标题验证与玩家实际战斗验证要分开报告。
9. 按 VALIDATION 完成玩家试穿。不能把文件哈希正确说成全部角色已通过战斗测试。

当前组合的关键状态：幻鬼绿裙已移除，保留浅色外搭并命名“幻鬼”；织绣海寇与剑星渡鸦不在基线内；白赤练双状态保留；其他具体条目以 outfits.json 为准。女性攻击、受伤与动作发力声音按角色切换，缺少对应类别用沐小葵；剧情对白保持原样。

在没有对应资源、未知版本、文件漂移或冲突时，停止依赖该条件的写入并给出确切原因。不能通过宣称“兼容”代替检查。
